# jishocli

Японский словарь, переводчик, карточки и поиск японской культуры в терминале.
Минималистичный вывод без рамок; цвет автоматически отключается в файлах и через `NO_COLOR`.

## Установка

Python 3.13+:

```bash
pip install -e .
# или uv sync, затем uv run jishocli …
```

## Словарь

```bash
jishocli search "учиться" -n 3
jishocli s 食べる --details
jishocli search 猫 --add 1
```

Написание, чтение, **ромадзи-произношение**, английские и машинные русские значения, части речи, частотность и JLPT.
`--details` добавляет варианты написания и сведения о кандзи: значения, он/кун-чтения и старый JLPT.
`--add N` сохраняет выбранный результат в карточки. Русский, английский и японский определяются автоматически;
для других языков задайте `--lang de`, `--lang fr` и т. п.

## Перевод фраз и разбор

```bash
jishocli phrase "Я хочу поехать в Японию"
jishocli translate "明日は学校に行きます。" --details
jishocli tr "Где находится вокзал?" --add
jishocli tr "日本語を勉強しています" --to en
echo '私は猫が好きです。' | jishocli tr -
```

По умолчанию японский переводится на русский, русский и английский — на японский.
`--lang` задаёт исходный язык, `--to ru|ja|en` — целевой.
Если одна из сторон японская, локальный Janome разбирает текст на слова: чтение хираганой,
ромадзи произношение,
начальная форма, часть речи и подсказки для частиц. `--details` добавляет форму склонения/спряжения
и словарные значения значимых слов из Jisho. `--add` сохраняет целую японскую фразу.

Это **морфологический**, не синтаксический разбор: связи между членами предложения не строятся,
подсказки частиц не учитывают весь контекст. Машинные переводы могут быть неточными.
Сложные имена и современный сленг могут распознаваться неверно.

## Аниме, манга и Япония

```bash
jishocli anime "葬送のフリーレン" -n 3
jishocli anime "Spirited Away" --details
jishocli manga "One Piece"
jishocli facts "Японская чайная церемония"
jishocli explore "Japanese festivals" --lang en
```

`anime` и `manga`: оригинальное название, тип, статус, оценка, число серий/глав,
жанры, краткий синопсис и ссылка на MyAnimeList. `--details` — полный синопсис.
Данные поступают из Jikan, включён фильтр SFW (не гарантия возрастной пригодности).
Русский запрос переводится на английский; официальное название может отличаться —
тогда попробуйте японское или международное. Описания возвращаются на языке каталога, обычно английском.

`facts` / `explore`: энциклопедический поиск Wikipedia, краткий текст и ссылка на статью.
По умолчанию ищется «Культура Японии». Поддерживаются `--lang ru|en|ja`, `-n N`.
Это поиск статей по запросу, а не генерация случайных или проверенных редакцией фактов;
область поиска не ограничена Японией. Проверяйте источники в статьях.

## Учёба и изображения

```bash
jishocli add 食べる --reading たべる --meaning "есть"
jishocli cards
jishocli due
jishocli study
jishocli stats
jishocli learn
jishocli learn 01
jishocli learn 01 --done
jishocli kanji 学 --save ./gaku.svg
```

Оценки 0–5 управляют интервалами повторения. `q` на оценке завершает сессию;
Ctrl+C/EOF сохраняют уже сделанные оценки. Карточки: `~/.jishocli/cards.json`.
`kanji` только сохраняет SVG, не рисует иероглиф в терминале.
SVG использует шрифт системы просмотра — нужен японский CJK-шрифт.

Учебник N5 содержит цель урока, подробное объяснение, фонетику, ромадзи, грамматику,
синтаксические шаблоны, примеры, практику, мини-тесты и внешние ссылки. Сначала
попробуйте ответить на вопросы самостоятельно, затем сверяйтесь с ответами урока.

## Веб-режим

Запустите локальное приложение:

```bash
jishocli web
# открыть http://127.0.0.1:8765
jishocli web --host 0.0.0.0 --port 8080
jishocli web --proxy http://127.0.0.1:8080
```

В браузере доступны: словарь, перевод фраз с разбором, курсы N5–N3, хирагана и катакана,
кандзи и рисование, тесты (включая аудио), OCR текста, аниме и манга с деталями и трейлерами,
читалка с закладками, карточки и статистика. Дизайн — современный адаптивный: «бумажная» светлая
и нейтральная тёмная темы, шесть акцентных цветов, переработанные шапка и футер, сетка карточек.
Выбор темы и акцента сохраняется в браузере.
Сервер использует тот же `~/.jishocli/cards.json`, поэтому CLI и web синхронизированы.
Остановка: Ctrl+C. По умолчанию сервер слушает только localhost.
Для нестабильной сети или корпоративного доступа используйте `--proxy`; также поддерживается
переменная `HTTPS_PROXY` (и стандартные proxy-переменные urllib). При запуске web-сервера
в журнал выводятся адрес, каждый HTTP-маршрут, ошибки и корректная остановка.

Маршруты можно открывать напрямую: `/learn`, `/lesson/01`, `/search?q=猫`,
`/translate?q=ありがとう`, `/kanji?q=学`, `/study`, `/anime?q=Frieren`,
`/manga?q=One+Piece`, `/facts?q=茶道`, `/cards`.
Также доступны `/study` и `/stats`.
API внешних сервисов остаются теми же, поэтому при недоступной сети поиск показывает понятную ошибку,
а учебник, карточки и уже сохранённый прогресс продолжают работать локально.

## Тесты и азбуки

Типы: `kana`, `romaji`, `vocab`, `particle`, `grammar`, `kanji`, `kanji-reading`,
`phonetics`, `sentence`, `audio`, `mixed`. `--mode recall` предлагает ввести ответ самому
(в web — переключатель «выбор/ввод»). Генератор убирает повторы, перемешивает тип в миксе
и показывает ошибки с правильными ответами после теста. У каждого урока есть свой интерактивный
тест; на странице урока — выбор урока, предыдущий/следующий и прогресс курса.

Азбуки рисуются так же, как кандзи: KanjiVG содержит хирагану и катакану. В рисовалке есть
порядок черт, режим сравнения, карта различий и процент схожести по покрытию/точности штрихов.

## Интерфейс

Шапка: бургер-меню с аккордеонами (все разделы), детерминированное открытие/закрытие,
блокировка прокрутки, закрытие по Escape/оверлею/ссылке и автосброс на широком экране.
Футер прижат к низу, адаптивность 1180/820/700/460/340px, сжатие HTML gzip,
кэш кандзи и порядков черт, параллельный разбор слов.

Страница карточек (`/cards`): вкладки «Мои карточки», «Генератор», «Проверка», «Данные».
Генератор выделяет слова из японского текста, показывает чтения/ромадзи/значения и сохраняет
отмеченные карточки пачкой. Меню слов есть в словаре, `/words`, результатах поиска и карточках:
озвучка, перевод, добавление, кандзи, рисование, тест.

Курсов восемь: START, PHRASE, KANJI, DRILL, N5, N4, N3, KEIGO (90 уроков).
Уроки стали интерактивнее: вкладки «Урок / Практика / Тест / Слова», конструктор предложений
из слов, тест урока, озвучка и перевод каждой строки.

## Команды

```bash
jishocli quiz --type audio --mode recall -n 10
jishocli anime 'Frieren' --genre Fantasy --year 2020 --sort SCORE_DESC
jishocli manga 'One Piece' --status RELEASING
jishocli courses
jishocli learn --course START 01 --done
jishocli ocr photo.jpg --lang jpn+eng
jishocli exam --level MIXED -n 20
jishocli exam --level N3 -n 10 --seed 5
jishocli import backup.json
jishocli goal 20

jishocli quiz --type kana --seed 42
jishocli kana --script hira --row basic
jishocli daily
jishocli export --format anki --out cards.txt
jishocli kanji 学 --save gaku.svg --strokes
```

- **Пять курсов**: START «С нуля» (10 пошаговых уроков: каны по строкам, звуки, первые слова, диалоги), N5 (24), N4 (12), N3 (10) и KEIGO «Вежливая речь» (6). Уроки START объясняют каждый знак и правило с нуля, с произношением и мнемониками. Список: `jishocli courses`, выбор: `jishocli learn --course START 01`. В web — `/learn?course=START`, `/lesson/START-02`.

Рисование (`/draw`): выбор образца из популярных кандзи, обводка по порядку черт KanjiVG,
кнопка «Проверить» сравнивает ваш рисунок с оригиналом по покрытию и точности штрихов
и показывает процент качества.

## Читалка манги и обучение по произведениям

```bash
jishocli read "chainsaw man"                 # список глав (MangaDex)
jishocli read "chainsaw man" --chapter 1     # страницы главы
jishocli read "chainsaw man" --chapter 1 --download ./pages
jishocli learn-from --anime "Frieren" --add  # слова из названия → карточки
jishocli learn-from "日本語のテキスト"
```

В web: `/reader` — поиск MangaDex, постраничное чтение (стрелки клавиатуры, режим «лентой»,
масштаб и ночной режим страницы), **закладки в localStorage** с кнопкой «Продолжить»,
языки «оригинал (ja) / перевод (en, ru)», скачивание страницы.
Панель под страницей запускает **OCR страницы** (Tesseract.js) и переводит распознанный текст
с ромадзи и разбором слов. Распознавание с картинки недоступно без загрузки модели — при первом
запуске браузер скачивает ~4 МБ с CDN.

## OCR как отдельный сервис

Web: `/ocr` — загрузите PNG/JPEG или укажите URL (разрешены AniList, MangaDex и публичные CDN),
выберите язык `jpn`, `jpn+eng` или `eng`. Движок Tesseract.js работает прямо в браузере:
результат можно озвучить, перевести, скопировать и разобрать на слова для карточек.
CLI: `jishocli ocr photo.jpg` — через локальный `tesseract` (нужно установить бинарник с языками
`jpn`/`eng`); если его нет, команда подсказывает использовать web-режим.

Карточка `/title?kind=&id=` показывает трейлер, официальные ссылки (Crunchyroll и др.),
связанные произведения, даты, студии и популярность. `/vocab` принимает свой японский текст.
Внешние официальные главы (MangaPlus и т. п.) скрыты — показываются только главы со страницами
на MangaDex.

## Дополнительно

- Слово дня: `jishocli daily` и виджет на главной web.
- Экспорт карточек: CSV и Anki (`jishocli export`, `/export.csv`, `/export.anki`).
- Серия дней подряд (streak) в `stats` и на web.
- Выбор акцентного цвета в шапке web (красный, индиго, матча, сакура, золото), сохраняется.
- Тёмная тема — нейтральная, без тёплых оттенков; светлая — «бумажная».

## Озвучка

Вместо браузерного синтеза (который читал кандзи как «китайскую букву» и слова по буквам)
используется **Google TTS**: сервер получает настоящий японский голос `/api/tts?q=...`
и кэширует MP3 в `~/.jishocli/tts/`. Кнопки 🔊 есть у слов, каны, уроков, карточек и тестов.
В CLI: `jishocli speak 'ありがとう' --out speech.mp3`. Если сервис недоступен — браузер
пробует родной `speechSynthesis` как запасной вариант.

## Рисование и навигация

Рисование кандзи: анимация **порядка черт** по данным KanjiVG, режим «Сравнить» (ваши мазки
поверх образца), оценка совпадения в процентах, счётчик черт. Навигация в шапке сгруппирована
в выпадающие меню «Учиться», «Язык» и «Мир»; активный раздел подсвечивается, в том числе
на страницах уроков и читалки.

## Экзамен N5–N1

Демо-экзамен с таймером, перемешанными уровнями и навыками, итоговой оценкой A–E,
ориентировочным уровнем JLPT, статистикой по навыкам и уровням, списком сильных/слабых сторон
и рекомендациями, что подучить. Разбор каждого ответа включает озвучку.

- Web: `/exam` → выбор уровня и количества → 30 секунд на вопрос → результат.
- CLI: `jishocli exam --level MIXED -n 20`.

## Читалка и четыре новые функции

- Полноэкранный режим манги: кнопка «Фокус» (или `F`) скрывает шапку, футер и панели;
  «Полный экран» использует нативный Fullscreen API. Есть `?focus=1` для прямого открытия.
- Резервная копия: `/export.json` и `jishocli import backup.json` восстанавливают карточки.
- Дневная цель повторений: `/stats` и `jishocli goal 20`.
- Избранное аниме/манги в `localStorage` с кнопкой «В избранное» на странице произведения.

Исправлен результат аудио-тестов: в разборе показываются прослушанный текст, ваш ответ,
правильный ответ, озвучка и объяснение.

## Книги на японском

Поиск Open Library и чтение доступных сканов через Internet Archive:

```bash
jishocli books こころ -n 5
```

Web: `/books?q=こころ` → карточки книг → `/book/read?ia=...` с встроенным просмотрщиком
и полноэкранным режимом только области книги.

## Генератор карточек

Генератор работает: `/cards?tab=generator` открывает нужную вкладку сразу, после сохранения
показывается подтверждение «Сохранено карточек: N». Кнопки озвучки и перевода RU/EN/JA
есть у слова и у значения.

## Управление с клавиатуры (читалка)

`← / →` — страницы, `F` — театральный режим только читалки (шапка сайта остаётся),
`B` — закладка, `O` — OCR, `T` — перевод, `?` — справка, `Esc` — закрыть.
Театр — не полноэкранный режим всего сайта, а развёрнутая область читалки в контексте страницы.

История экзаменов (последние 10 результатов) сохраняется в `localStorage` и показывается на `/stats`.

Шесть новых разделов в меню «Практика»:

- `/conversation` — практика общения по сценариям (6 диалогов, выбор реплики, разбор и TTS);
- `/shadowing` — аудирование: фразы в обычном и медленном темпе;
- `/builder` — конструктор предложений из случайного урока;
- `/random` — случайное слово с озвучкой и переводом;
- `/flashcards` — быстрый тренажёр карточек;
- `/favorites` — избранное, закладки и история экзаменов в одном месте.

Добавлен курс BASIC (10 уроков базовых конструкций) — всего **9 курсов и 100 уроков**.

Читалка манги теперь кэширует страницы на диск (`~/.jishocli/cache/manga`, 30 дней),
предзагружает соседние страницы и выдаёт `Cache-Control: 1 week`. Театральный режим разворачивает
только читалку, шапка сайта остаётся. Клавиши: `←/→`, `F`, `B`, `O`, `T`, `?`.

Произношение: кнопки «обычно» и «медленно» используют один и тот же TTS с разной скоростью
воспроизведения (`playbackRate`), без низкокачественного синтеза браузера.

Выбор акцентного цвета: шесть палитр плюс сброс к красному по умолчанию, подсветка фокуса
и активных состояний.

Озвучка: серверный Google TTS с кэшем, ретраями альтернативных endpoint’ов и разбиением
длинных текстов на части. Браузерный синтезатор больше не используется, поэтому голос одинаковый.
Кнопки «Перевод / Медленно / Оригинал / Копировать» есть в плашке перевода; плашка ограничена
по высоте, прокручивается и не уезжает за экран (на мобильных — на всю ширину). Ошибки озвучки
показываются тостом.

## Сервисы, приватность и ограничения

- Jisho — словарь; kanjiapi.dev — сведения о кандзи.
- MyMemory — перевод; исходный текст отправляется внешнему сервису. Не передавайте секреты.
  Ограничение одного запроса — 500 байт UTF-8, также действуют квоты сервиса.
- Каталоги AniList → Tenrai → Jikan; при сбое прокси движок пробует прямое соединение,
  взрослый контент отфильтрован.
- MangaDex — главы и страницы манги (легальные сканлейты), включая японский оригинал.
- Tesseract.js — OCR в браузере (модель jpn загружается с CDN); локальный `tesseract` — опция для CLI.
- KanjiVG — порядок черт кандзи (CC BY-SA 3.0, Ulrich Apel).
- Wikipedia — статьи и ссылки. Поисковые запросы отправляются соответствующим сервисам.
- Морфологический разбор Janome и карточки работают локально; перевод и поиск требуют сети.
  Сбой необязательного русского перевода не скрывает английское значение.
- Повторные одинаковые переводы кэшируются только в памяти текущего процесса.

Справка: `jishocli --help`, `jishocli phrase --help`.
Тесты: `python -m unittest discover -s tests` (после установки).
